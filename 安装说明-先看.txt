HOI4 模组开发助手 skill · v2.31
制作者：猫妖
=============================================

【这是什么】
一个给 AI 助手（Claude Code / ZCode / DeepSeek Harness 等）用的 HOI4 模组开发技能包。
安装后对 AI 说「我要制作一个钢铁雄心4的XX mod」即可进入引导流程：
配置目录 → 选择任务 → 路线图确认 → 逐项制作（带验证点）。

【仓库结构】
  HOI4-skill-AImodding/         ← skill 本体（SKILL.md / references / scripts）
  HOI4-skill-AImodding.zip      ← 打包好的安装包（解压即用）
  安装说明-先看.txt             ← 本文件

【安装方法】
方式一（推荐，用压缩包）：
  把 HOI4-skill-AImodding.zip 解压到 AI 助手的 skills 目录，
  解压后得到 skills\HOI4-skill-AImodding\ 即可。

方式二（用文件夹）：
  把 HOI4-skill-AImodding 整个文件夹复制到 AI 助手的 skills 目录。

skills 目录位置：
· Claude Code：      C:\Users\<你>\.claude\skills\
· ZCode：            C:\Users\<你>\.zcode\skills\
· DeepSeek Harness： <你的工作区>\.dsh\skills\

装一个即可，放好后重启或新开会话，对 AI 说「我要制作一个钢铁雄心4的 mod」即可触发。

【首次使用】
AI 会引导你配置两个路径（只配一次，写入 skill 目录下的 config.json）：
1. 钢铁雄心4 游戏根目录（只读参考，绝不写入）
2. 你的 mod 工作目录

【注意】
· config.json 含本机路径，已列入 .gitignore，请勿提交或再分发
· 游戏根目录永远是只读参考

  把 SKILL.md 里的 name 与文件夹名改为 hoi4-skill-aimodding 即可
